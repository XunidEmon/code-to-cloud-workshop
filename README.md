# Code to Cloud — Workshop Materials

A 3-Day Online Hands-On Workshop organized by 
**Programming & AI Club, Dept. of EEE, University of Asia Pacific**

## 📅 Event Details
- **Dates:** 9, 10 & 24 October 2026
- **Time:** 10:30 PM – 12:00 AM (BST)
- **Platform:** Google Meet

## 🎯 What You'll Learn

### Day 1 — Frontend
Build your website from zero to your first live website.

### Day 2 — Backend
Take it live with Git, GitHub & VS Code. Connect your website with backend.

### Day 3 — IoT
Show MCU data live. Stream sensor data to your website.
